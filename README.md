# Scene Relay

A compact, original browser game about choosing the next beat in an improv
scene. Make five creative decisions, build room energy, and earn the best final
applause you can.

## Run locally

No build step or dependencies are required. Serve the repository with any static
file server, then open the local URL in a browser:

```bash
python3 -m http.server 8000
```

## Controls

- Select one of three next-beat choices in each scene.
- Strong scene choices build score, room energy, and your streak.
- Use **Run it again** on the result screen for a fresh run.

The game uses original game text and visual styling.
